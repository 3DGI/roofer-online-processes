# Topic 1 project plan

This repository implements the OGC API - Processes layer for Roofer Online. Topic 4 is a
downstream consumer and is intentionally outside this repository.

| Milestone | Due | Proposal work package | Hours |
| --- | --- | --- | ---: |
| Gap Analysis and Design | 2026-09-03 | Endpoint/workflow mapping, schemas, architecture, POC assessment | 26 |
| Core OGC Processes Implementation | 2026-10-01 | Four processes, execution, jobs, results, auth, adapter | 64 |
| Compliance and Interoperability Validation | 2026-10-20 | CITE, Geonovum checker, independent-client and failure testing | 26 |
| Demo, Documentation and Handoff | 2026-11-03 | Public demo, report, videos, release and six-month handoff | 25 |

## Definition of done

- The four proposal process identifiers are discoverable through OGC API Processes v1.0.
- Sync and async execution, status, results, dismissal, and applicable callbacks are tested.
- Roofer Online authentication and ownership rules are preserved by the host adapter.
- CITE Team Engine and Geonovum validation finish with zero errors/faults for advertised classes.
- Public documentation, examples, implementation findings, and release artifacts are available.
